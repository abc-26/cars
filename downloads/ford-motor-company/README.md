# Ford Motor Company

Resources and documents related to Ford Motor Company.

## File Naming Convention

Use the following naming format for Order Guide files:

```text
[Model Year]-[Ford or Lincoln]-[Model Name]-Order-Guide-[yy-mm-dd].pdf
```

- **Model Year:** The vehicle model year, written as four digits.
- **Ford or Lincoln:** The vehicle brand.
- **Model Name:** The vehicle model name. Use hyphens between words.
- **Order-Guide:** The document type.
- **yy-mm-dd:** The document date, using a two-digit year, month, and day.

**Examples:**

- `2027-Ford-Super-Duty-Order-Guide-26-10-20.pdf`
- `2026-Lincoln-Navigator-Order-Guide-26-10-15.pdf`
